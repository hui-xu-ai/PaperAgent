# PaperAgent v1.5.0

> 本地单用户文献 AI 阅读 / 翻译 / 知识库管理应用（Windows 免装包 + 源码两种用法）。
> 上一个公开版是 v1.4.0；本版是**阅读器体验**的一次大迭代（Markdown 阅读器 + PDF 阅读器）。

## 升级须知（先读这一段）

| 问题 | 答案 |
|---|---|
| 会丢数据吗？ | **不会。** `DATA_FORMAT` 保持 4，本版无迁移，首启不会动你的库。 |
| 要重新解析 PDF 吗？ | **不用。** 解析产物与知识库目录格式未变。 |
| 要重新编译吗？ | **不用。** `_note.md` / `_wiki.md` / `_relations.md` 全部沿用。 |
| 要动手做什么？ | **不用。** 纯前端体验升级，覆盖 `PaperAgent.exe` + `_internal/` 即生效。 |

升级前照例备份 `data/` + `knowledge_base/`（`docs/UPGRADE.md`）。

## 本版亮点

### Markdown 阅读器

- **阅读位置记忆 + 进度条**：切文档、切标签、重开应用都自动回到上次读到的位置，顶部 3px 进度条显示阅读比例；
- **目录大纲抽屉**：按标题层级跳转（容器内滚动，不再误滚整页/遮工具栏）；
- **`[[双链]]` 真跳转 + 「← 返回」**：点双链跳到目标笔记后，工具栏出现实心蓝「返回」按钮，多级 LIFO 连点可逐级回到来源，返回时滚动位置精确复原；
- **`[Pxxx]` 段落引用可点解释**：编译产物里的段落引用变成可点上标，悬浮窗显示该段原文（章节+正文），支持**中/英一键切换**与公式渲染，字体与阅读器一致；
- **编辑态升级 EasyMDE**：工具栏/分屏预览/Ctrl+S/按文档隔离草稿；进入编辑自动定位到当前阅读章节，退出复原阅读位置；
- 渲染内核抽离为独立库 `mdkit`（业务无关）+ 业务插件外置，阅读/编辑/悬浮窗排版统一 Inter 字体与读者字号。

### PDF 阅读器

- **清晰度**：按设备像素比（上限 2）渲染，HiDPI 屏不再模糊；
- **性能**：可视窗口懒渲染 + 离屏释放，大文件不卡不吃内存；
- **文本层**：文字可选、可复制（此前是纯图片无法选中）；
- **文内搜索**：关键词高亮 + 上/下一条跳转 + 命中计数；
- **大纲书签抽屉**：按 PDF 书签树跳转章节；
- **平移/缩放**：放大后可滚到页面最左缘（修旧版裁切），支持手型拖拽与中键平移。

### 其他

- 修复目录跳转后工具栏消失、切换文档阅读位置被误清零、双链一次点击双压栈等一批交互缺陷；
- 前端阅读器模块（`js/reader.js`）与样式（`style.css`）同步上述能力。

## 下载即用

1. 下载 Assets 里的 **`PaperAgent-v1.5.0-win64.zip`**（免装 Python）；
2. 解压到**空目录**（别放 C 盘只读位置）；
3. 双击 `PaperAgent.exe` → 「设置中心」填 Key：
   - `MINERU_API_KEY`（解析必需，<https://mineru.net/apiManage> 免费申请）
   - `DEEPSEEK_API_KEY`（翻译 / 编译 / 问答必需）

数据、密钥、文献都在**解压目录内**（`data/ library/ knowledge_base/ .env`），
升级只覆盖 `PaperAgent.exe` + `_internal/`。

## 已知限制

- 仅 Windows；单用户本机应用（只监听 127.0.0.1，**无鉴权**，勿暴露公网）；
- 解析依赖 MinerU 网络；翻译/编译/问答依赖 OpenAI 兼容 LLM；
- PDF 阅读器暂未做：缩略图侧栏、双页并排、夜间反色、批注/高亮持久化（C 组，规划中）；
- PDF 搜索高亮为 span 级 best-effort（跨行断词个别不高亮，非缺陷）；
- ANN 索引（HNSW/IVF）未做——10 万篇以内走全量精确检索；
- 主题 MOC（`_topics/`）与「索引健康」前端卡片尚未实现（后端接口已就位）。

完整变更见仓库 `CHANGELOG.md`；知识库架构与设计哲学见 `docs/KNOWLEDGE-BASE.md`。
