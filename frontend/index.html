① 📥 导入 bib 文献

支持 WoS 导出的 .bib 文件。导入时自动补全期刊全称（基于映射表）。
增量导入：可直接导入新的 bib 文件，系统按 DOI 自动去重——已存在的文献跳过（导入结果会显示"跳过重复 N 篇"），仅新增文献入库，无需清空重建。

方式一：输入文件路径
或
方式二：上传文件

② 🧹 文献清洗

基于年份、影响因子、分区、库内引用组合筛选，移除低价值文献（可选步骤）。先"关联期刊指标"再"计算预览"，确认后清洗。

③ 🧬 补全元数据

通过 DOI 从 OpenAlex/Crossref 补全标题、摘要、作者、被引次数等（含参考文献）。补全后可用于清洗第二阶段（按被引次数筛经典文献）。

④ 📖 期刊名规范化

将缩写期刊名（如 ADV MATER）统一为全称（如 Advanced Materials），经 OpenAlex 解析并写入映射表。已映射的期刊秒级命中，约需 2 分钟。

⑤ 🕸️ PaperRank 计算

基于库内引用图谱计算文献影响力排名。结果可在「图谱」页查看 Top 20 与共被引聚类。

⑥ 🔧 向量索引

用 bge-m3 为文献构建向量索引，供三层漏斗检索的语义召回。新增文献后需重建以纳入索引。

🚀 一键全流程

按顺序自动执行：元数据补全 → 期刊名规范化 → PaperRank → 向量索引。
主题编译耗 token，已剥离为手动操作，请在「主题」页按需触发。

＋ 导入

📄 PDF 导入

上传 PDF 进入解析流水线。解析 + 编译（默认）= 解析 → 纳入知识库 → 编译 L1，跳过翻译（省 token）；全流水线 = 再加翻译 + 总结（耗 token）；仅解析 = 不纳库不编译不翻译，0 token。可多选批量。

📝 Markdown 导入

官方 md 免重新解析 PDF，直接进知识库（同步笔记/详情/检索文件；冻结原则：不覆盖已有内容）。

📚 Bib 引用导入

导入 .bib（WOS 导出格式）→ 元数据（papers_meta，bib 权威）+ 引用关系 + 检索索引。无 DOI 的条目会跳过并给出警告。

📎 支撑信息 / 审稿意见 / 其他附件

把 SI、审稿意见、原始数据挂到某篇文献下：落在 library/<该文献>/attachments/<类型>/，与该文献同生共死； 纯本地处理（不调 AI、0 token），可读文本会自动进检索索引（可被「知识库问答」召回）。 不选父资源则按内容指纹（nd-<md5>）单独存放。
